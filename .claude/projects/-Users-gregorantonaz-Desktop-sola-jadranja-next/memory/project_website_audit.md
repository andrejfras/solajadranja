Full audit received 2026-03-27. Key takeaways:

**Core problem:** Site sells courses (admin/catalog feel) instead of outcomes (freedom, sea lifestyle, charter readiness).

**Quick wins (do first):**
1. Rewrite homepage hero: transformation-focused, not inventory-focused
2. Add dominant CTA sitewide: "Rezerviraj termin"
3. Trust strip under hero: 98% success, reviews count, guarantee, year-round dates
4. Turn boat rental into a conversion block on homepage
5. Fix any trust-damaging technical issues

**Strategic improvements:**
1. Rebuild homepage as funnel (hero > trust > 3 intent paths > dates > flagship offer > testimonials > CTA)
2. Create flagship bundle: boat license + VHF + practical + rental benefit
3. Redesign registration flow: step-by-step, fewer fields, mobile-first
4. Integrate boat rentals as the brand moat / outcome payoff
5. Unify brand architecture across all properties

**Positioning:** "Pri nas gres od nic do prve samostojne plovbe" — from zero to first independent boat day.

**Why:** Current site has all ingredients for category leadership (broad offer, guarantee, online course, rentals) but presents them as a cluttered catalog instead of a compelling funnel.

**How to apply:** Every design/copy decision should prioritize transformation narrative over feature listing. Rentals = the payoff, not a side note.
